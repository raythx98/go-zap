# Modules

Per-package summaries — what each package owns and its public interface.

---

## `cmd/api/main.go`

Application entry point. Loads config, creates resources, registers routes, starts the HTTP server.

---

## `endpoints/endpoints.go`

Route registration. Maps HTTP paths and methods to controller handlers with middleware chains.

- `POST /api/auth/v1/register` — Basic Auth
- `POST /api/auth/v1/login` — Basic Auth
- `POST /api/auth/v1/refresh` — Refresh Token
- `POST /api/auth/v1/logout` — Access Token
- `GET /api/urls/v1` — Access Token
- `POST /api/urls/v1` — JWT or Basic Auth
- `GET /api/urls/v1/{id}` — Access Token
- `DELETE /api/urls/v1/{id}` — Access Token
- `POST /api/urls/v1/redirect/{shortLink}` — Basic Auth
- `GET /swagger/` — Swagger UI

---

## `controller/`

HTTP handlers. One file per domain: `auth.go`, `urls.go`, `redirects.go`.

Pattern:
1. Unmarshal request body from JSON.
2. Validate using `gohelpme` validator.
3. Call the corresponding service method.
4. Write JSON response or error.

Controllers never contain business logic.

---

## `service/`

Business logic. One file per domain: `auth.go`, `urls.go`, `redirects.go`.

Each service file has a corresponding `_test.go` file with unit tests using mockery-generated mocks.

**Interface pattern:** `IAuth`, `IUrls`, `IRedirects` — all services expose interfaces for testability.

---

## `repositories/repositories.go`

Data access layer. Wraps SQLC-generated `db.Queries` behind an interface.

**Interface:** `IRepository` with methods for users, URLs, and redirects.

All database calls go through this interface — never call `sqlc/db` functions directly from service or controller layers.

---

## `dto/`

Data Transfer Objects for request and response types. One file per operation.

- `create_url.go` — `CreateUrlRequest`, `CreateUrlResponse`
- `get_url.go` — `GetUrlResponse`
- `get_urls.go` — `GetUrlsResponse`
- `login.go` — `LoginRequest`, `LoginResponse`
- `register.go` — `RegisterRequest`
- `redirect.go` — `RedirectRequest`
- `url.go` — `UrlDto` (shared representation)

DTOs are annotated with `swaggo/swag` Swagger annotations and `go-playground/validator` validation tags.

---

## `resources/`

Dependency injection and wiring.

- `resources.go` — factory functions: `CreateTools()`, `CreateRepositories()`, `CreateServices()`, `CreateControllers()`.
- `type.go` — `Tools` struct, `Repositories` struct, `Services` struct, `Controllers` struct.

---

## `tools/config/`

Environment variable loading using `envconfig`.

**Key type:** `Config` struct with `APP_URLSHORTENER_*` fields.

---

## `tools/postgres/`

PostgreSQL connection pool wrapper.

**Key interface:** `IPostgres` — `Pool() *pgxpool.Pool`.

---

## `tools/crypto/`

Password hashing interfaces. Implementation injected from `gohelpme`.

---

## `tools/mw_helper/`

Middleware setup and rate limiting helpers. Thin wrapper around `gohelpme/middleware`.

---

## `tools/pghelper/`

Database utility functions for nullable fields and common patterns.

---

## `tools/random/`

10-character alphanumeric short URL generation.

---

## `tools/zerologger/`

Structured logging setup using zerolog.

---

## `sqlc/query.sql`

SQL queries for code generation. **Source of truth for all database queries.** Edit here, then run `make sqlc`.

---

## `sqlc/db/`

Auto-generated by `sqlc`. **Do not edit.** Contains `Queries`, model structs, and type-safe query functions.

---

## `migrations/`

Database migration files in `golang-migrate` format.

- `000001_init_table.up.sql` — creates `users`, `urls`, `redirects` tables.

---

## `docs/`

Auto-generated Swagger documentation. **Do not edit** `docs.go`, `swagger.json`, `swagger.yaml`. Regenerate with `make swagger`.

---

## `mocks/`

Auto-generated mockery mocks for service and repository interfaces. Regenerate with `mockery --all`.
